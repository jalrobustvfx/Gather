    Connected collections

    • No collections connected yet.

    Keep the local Gather server running for automatic backups. If the computer is asleep or the server is off, an overdue backup runs when it starts again. The Chrome extension syncs while Chrome is running; browser collections sync while their Gather tab is open. Backups use the latest synced copy.

    How to restore a backup

    Each dated backup folder contains a browser or Chrome collection JSON file. Use Import collection to restore it; links are merged with your existing collection. The folder also includes watch-state.json. To restore watches and updates, stop the server, replace the file with the same name in Gather’s .gather folder, then start the server again. Keep the existing file as a spare copy.

    Keep a good find, in one click.

    1. Open chrome://extensions in Chrome.
    2. Enable Developer mode, then choose Load unpacked.
    3. Select NewsGrabber\extension, the prepared Chrome folder, rather than the project root.
    4. Pin Gather. Press Alt+Shift+S on a page to capture a screenshot and organize it. You can change the shortcut in chrome://extensions/shortcuts.

    After updating the source, run build-extension.ps1 again before reloading the extension. Open your collection from the extension to see extension saves. Browser preview and extension storage are separate; use Export and Import to move your collection between them.
